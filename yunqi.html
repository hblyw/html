GitHub 配置 ✕

记住配置（下次不用再填）
仓库必须是 Public；发布前请在仓库开启 GitHub Pages（Settings → Pages → Deploy from a branch → main）。不会配置请点右上角「配置教程」里的向导。

第一次用？一步一步配置 GitHub ✕

  1. 注册 GitHub：打开 github.com → 右上角 Sign up，填邮箱/密码/用户名，验证后完成。
  2. 建公开仓库：+ → New repository，填英文名，可见性选 Public，Create repository。
  3. 生成 Token：头像 → Settings → 左侧最底部 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)；Note 随便填，Expiration 选 No expiration，勾选 repo，Generate token，复制 ghp_ 开头字符串（只显示一次）。
  4. 开 GitHub Pages：仓库 Settings → Pages → Deploy from a branch → 选 main → Save。
  5. 回来填好发布：点右上「设置」填 用户名/仓库名/Token，粘贴或上传 HTML，点「生成链接」→「一键发布」，等 1~2 分钟用返回的链接打开。
常见问题：
· 上传失败/403：Token 没勾 repo，或仓库是 Private。
· 打开是代码/404：确认开了 Pages，并等 1~2 分钟部署。
· 想更新：改好再发布一次，链接不变。
· 想删除：登录 GitHub 进仓库删文件。
· 文件名尽量用英文更稳。

许可协议 ✕

本工具为本地单文件网页应用，仅调用 GitHub 官方接口完成 HTML 上传与发布，可自由使用与修改。

发布内容存于你的公开 GitHub 仓库，请勿放入身份证、密码等隐私文件。

生成 Token 属于你的账号凭据，请勿泄露。
